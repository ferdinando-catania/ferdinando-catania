## Hi, I'm Ferdinando 👋

**Embedded Firmware & Hardware Engineer** working on high-reliability electronics for defence, aerospace and communications, and **co-founder of [Stabiae Tour](https://stabiaetour.com)**, a small tourism business in Castellammare di Stabia (Italy) that I run largely with code and AI agents.

### 🔧 What I do

- **FPGA & digital design**: VHDL, Xilinx Vivado, SoC-based boards for radar, sonar and RF/IF signal processing
- **Hardware design**: PCB design (incl. high-speed protocols), RF & microwave, analog front-ends
- **System integration & test**: debugging and validation of electrical interfaces (LAN, RS-422/485, MIL-STD-1553), ICD compliance, test reports
- **Embedded & tooling**: Linux, MATLAB/Simulink, LTspice, Qucs-S, Autodesk EAGLE

### 🚀 Side project: Stabiae Tour

Walking tours, boat tours and excursions on the Sorrento Coast, with an operations stack I built myself:

- Static website + Cloudflare Pages Functions (Stripe checkout, webhooks, D1)
- GitHub Actions for build, checks and deploy
- AI agents (Claude) for content, bookings, admin and consistency across booking platforms
- Self-hosting experiments on Oracle Cloud Always Free
